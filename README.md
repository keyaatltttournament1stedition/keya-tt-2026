# KEYA ATL Table Tennis Tournament 2026

Schedule, draws and live scores for the 1st KEYA ATL Table Tennis Tournament, 28–29 Nov 2026, Keya Around The Life.

- The public page is `index.html`, served by GitHub Pages. Nobody needs a login to open it.
- Live scores come from the organisers' Google Sheet "KEYA TT 2026 – Live Scores (admin)". The page re-reads the sheet every 30 seconds.
- Organisers fill in **Status** (LIVE / DONE), **Winner** (A or B) and **Game scores** (e.g. `11-7, 9-11, 11-5`). Winners move into the next round automatically.
